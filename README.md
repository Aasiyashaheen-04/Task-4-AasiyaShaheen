# Data Analytics Project 4 – Data Visualization

## Project Overview
This project focuses on creating visual representations of data to communicate insights clearly.

## Objective
To analyze the dataset and present important findings using appropriate charts and visualizations.

## Visualizations Created
- Sales Trend Over Years – Line Chart
- Sales by Product – Bar Chart
- Sales by Referral Source – Bar Chart
- Order Status Analysis – Bar Chart

## Key Insights
- Sales were highest in 2023 and declined in the following years.
- Instagram generated the highest sales among referral sources.
- Chair and Printer were among the top contributors to sales.
- Cancelled orders formed the largest order-status category.

## Tools Used
- Microsoft Excel
- PivotTables
- Data Visualization
- Data Analysis

## Deliverable
The completed Excel workbook containing the analysis, visualizations, and key insights is included in this repository.
